# Hindi glossary

Terms used on `/hi-in/` (हिंदी, Devanagari) and `/hi-latn-in/` (Hindi in Latin script) pages. Write spoken, everyday Hindi. Keep the English words buyers and supervisors actually say, in Devanagari. Keep acronyms in Latin script (EPF, ESIC, HR, PPE, MHE). Use the nukta consistently (फ़ैक्टरी, ज़रूरत, स्टाफ़).

## Banned words in Hindi

These have the same force as the English banned words in `docs/claim-policy.md`, and `pnpm lint:slop` checks for them: गारंटी, हमेशा, कभी नहीं, सर्वश्रेष्ठ, सबसे अच्छा, बेस्ट, नंबर 1 / नंबर वन.

## Latin-script spelling (hi-Latn-IN)

hi-Latn-IN pages use Hindi grammar in Latin script. English nouns stay in English: *labour, workers, shift, site, records, supervision*. Use one spelling for each common word:

| Word | Spelling | Not |
|------|----------|-----|

| और | aur | or |
| के लिए | ke liye | k liye, ke liya |
| ज़रूरत | zaroorat | jarurat, zarurat |
| बताइए | bataiye | batayein, btaiye |
| हिसाब से | hisaab se | hisab se |
| हाँ | Haan | Ha, Han |
| ठेकेदार | thekedar | thekedaar |

| नहीं | nahi | nahin, nhi |

| मशीन / मशीनें | machine / machines | mashin |
| Fee line | Koi fee nahi. | Koi fee nahi lagti. |

Verb forms: buttons, titles and short calls to action use **-ein** (karein, bhejein, chunein, daalein). Running sentences that ask the reader something may use **-iye** (bataiye, bhejiye, likhiye), as today. Don't mix both in one sentence.

hi-Latn-IN eyebrows are written in sentence case (`:lang(hi-Latn) .eyebrow` in `globals.css`): tracked capitals make romanised Hindi hard to read. hi-IN and English eyebrows stay uppercase. Banned words also apply in Latin script: *guarantee, hamesha, kabhi nahi, sabse best, number 1*.
